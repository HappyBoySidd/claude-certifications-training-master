CCDV-F SIM-03 — Support Agent with the Claude Agent SDK

How to use this: read the scene, then work through the decisions on paper, or paste the scene and the decisions list (not the answer key) into Claude and ask it to run the simulation one decision at a time with no hints. Open the coach key only when you've finished.

Primary domains: 1 Agents and Workflows, 6 Prompt and Context Engineering, 8 Tools and MCPs · Decisions: 10 · Time: 20 min

Scene (original, written from the official objectives)

You're building a support agent for a home-internet provider with the Claude Agent SDK. It has four tools: check_account, run_line_test, schedule_technician and issue_credit. A knowledge-base subagent looks up troubleshooting articles. Conversations run long, the line-test service is flaky, and the business rule is firm: no credit is ever issued to an unverified account or above the agent's limit without a person approving it.

The decisions (answer these before you open the key)

  1. In your first custom loop the customer never gets an answer after the agent calls a tool
  2. Password resets always follow the same three fixed steps
  3. Enforcing the credit rule
  4. The agent calls run_line_test when it should check for an area outage
  5. run_line_test times out
  6. Line-test output is thousands of lines and fills the context
  7. After a long chat the agent forgets the account was already verified
  8. The knowledge-base subagent returns articles for the wrong router model
  9. Tone and refund policy are pasted into every user message and ignored after many turns
  10. Which tools the knowledge-base subagent gets

CCDV-F simulations

These six scenarios are our own. The Developer exam guide publishes no official scenario list, so each one is written from the guide's Section 6 objectives and the saved Claude docs. Rehearse all six. Across Simulation 2: Document Pipeline: Batch, Streaming and Caching to Simulation 7: Cutting Cost and Latency on a High-Volume Classifier the 60 decisions roughly follow the exam weights, so Applications and Integration (Domain 2) gets the most practice.

CCAO-F lessons (Claude Certified Associate: Foundations)

Last reviewed: 2026-09-29

One lesson per official domain, plus Lesson 0: Orientation: how this exam thinks orientation. Each lesson has the big idea, what to know, a worked example, traps, a hands-on "Try it" and a "Done when" checklist. Lesson 1: Prompting and Task Execution–Lesson 7: Troubleshooting and Optimization each end with a practice drill at an 80% pass bar.

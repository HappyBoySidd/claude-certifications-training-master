Your learning route: Start with one application you can picture, then choose a complete situation. Each taught layer shows a failure, asks a technical original exam-style question first, then explains the repair simply after you choose. Use this directory for its particular depth, not as another mandatory course. Return to the complete learning journey.

Each page below teaches one official task statement. Work through them in number order; each page lists its prerequisites and a realistic time.

Practice changed constraints

Use the decision atlas to compare the base choice, changed constraint and failure path. Finance changes approval, monetary consistency and source-age risk; Legal changes evidence attribution, privilege/access and ambiguity; Marketing changes consent, segment criteria and false-positive cost. These are synthetic transfer contexts, not official industry weightings. Keep the underlying Claude mechanism explicit.

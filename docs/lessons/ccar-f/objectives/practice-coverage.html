How to read this page

  • The shared practice bank has 311 CCAR-F questions: 249 mapped with a clear fit, 51 mapped with an uncertain fit, and 11 unmapped. These add up to 311.
  • Clear means one official task statement plainly describes what the question tests. Uncertain means more than one fits, or the fit is loose. Unmapped means no single task statement fits; for those, use the domain lesson: Agentic Architecture and Orchestration, Tool Design and MCP Integration, Claude Code Configuration and Workflows, Prompt Engineering and Structured Output, Context Management and Reliability.
  • 8 questions map to two objectives, so they appear under both. The objective column therefore adds up to more than 311; the bank total counts each question once.
  • Mappings retain author history plus the dated independent item/legacy review. Independent check: accuracy_review2026-10-14; exact item dispositions in assessment/canonical-item-review.json; uncertain mappings retained; PLAN-02 eight-item corrected batch navigation_regression2026-10-21; 18 OPL task-level mappings independently reviewed benchmark_ingestion2026-10-22. Treat every mapping as a pointer, not a verdict.
  • 0 objectives have no question at all (none). Task coverage does not establish complete individual skill-bullet mastery; consult the per-bullet ledger. Practise those objectives with the lesson's Try it section and the industry cases.
  • The practice app records objective-level first-attempt, repeat and assisted evidence; your progress page shows these separately from checklist ticks.

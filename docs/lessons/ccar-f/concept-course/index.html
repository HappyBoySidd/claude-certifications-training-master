Start with an application · Full learning journey · Learn architecture through eight application cases · Practise 30 decision variants

Your learning route: Start with one application you can picture, then choose a complete situation. Each taught layer shows a failure, asks a technical original exam-style question first, then explains the repair simply after you choose. Use this directory for its particular depth, not as another mandatory course. Return to the complete learning journey.

Start with a familiar screen and follow its data. Then learn the technical names for the choices you make. This course is an original teaching bridge to the existing CCAR-F objectives, not a new exam blueprint or a promise of every possible exam scenario.

Reading setup: none. No account, API key, installation or paid credits are required. Read the traces and answer aloud or on paper. Any runnable lab linked below has its own prerequisites; a teaching contract here is not executable SDK code.

Each lesson follows scene → trace → choices → changed constraint → recall → application. Read one lesson, close it, explain its trace aloud, then reveal the decision answers. If you cannot explain why the alternative loses, use the linked objective before attempting timed practice.

Keep the learning arc connected

Use application anatomy when a component is unfamiliar. Use the objective map for precise task coverage and the decision atlas for more changed constraints. The architecture cases combine concepts into complete applications. The SIM collection tests larger decisions; Lab 08 offers paper-first practice and an optional local exercise. Finish a study session with flashcards, then return to the concept behind any missed answer.

The examples use fictional records. Finance, Legal and Marketing are transfer contexts, not asserted official industry weightings. Reading this course does not replace the 30 objective lessons or validate an exam-readiness score by itself.

Pair a local lesson with an official course

Use the official-course companion on the CCAR-F hub when you want a second explanation or actual implementation work. It identifies core companions, optional on-ramps and enrichment, prerequisites and the concrete decision to practise afterward. Our reading route still requires no installation. A completion badge is separate from certification and scenario readiness.

Your learning route: Start with one application you can picture, then choose a complete situation. Each taught layer shows a failure, asks a technical original exam-style question first, then explains the repair simply after you choose. Use this directory for its particular depth, not as another mandatory course. Return to the complete learning journey.

The saved July 2026 exam guide v1.0 describes selection of 4 of these 6 scenario families (Tier 1). This is the saved blueprint baseline, not an exhaustive inventory of possible application problems. Each page walks one scenario from start to finish, the way you would design it for real:

  • The whole job in one chart: the order of steps, the decisions and the failure paths.
  • Step by step: what you decide at each step, the design rule (exam wording where it matters), and what can go wrong, with the exact signal or error code and what the design does about it.
  • Try the paper decisions: 10 what-if questions with answers, written for this site. They are practice, not real exam questions.

How to study one scenario (about 45 minutes the first time): read the walkthrough (20 min), try its 10 what-ifs with the answers closed (10 min), then run the matching simulation (15 min).

Reading the charts. Each box is a step. Each diamond is a decision. A green PICK box is the right move. A pink dashed NOT box is the tempting trap.

Read these decisions conditionally

Batch requires independent eligible Messages requests, no dependent local iterative state, and an explicit deadline/expiry/recovery contract. Waiting overnight alone is insufficient; the 24-hour processing window does not guarantee successful completion. Tool choice selects a supported invocation mode; strict/schema enforcement constrains structure; application evidence checks establish meaning. A declared optional null need not trigger human review; required missing, ambiguous or conflicting evidence follows the stated review policy. These qualifications apply to gallery previews as well as full walkthroughs.

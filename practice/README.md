# Practice tool

A practice-question tool for the four Claude certifications. It is one HTML file that works offline.

**None of these are real exam questions.** The real exam bank is confidential. Use this tool for
practice and pacing, and trust Anthropic's official exam guide wherever the two disagree.

## How to use it

1. Open [`index.html`](index.html) here, then choose **Download raw file** (or **Raw**, then save the page).
2. Open the downloaded file in your browser. It needs no internet connection.
3. Pick an exam, then **Start mock**, drill one domain, or choose **Fix my mistakes** to redo the
   questions you got wrong.

Your answers are saved only in your own browser (local storage). Nothing is sent anywhere.

## Original release provenance (historical)

The following table describes the initial release and is retained as provenance. Use the generated current inventory above for today's population.

| Exam | Anthropic sample questions (Tier 1) | Amey Thakur's questions (Tier 2) |
| --- | --- | --- |
| CCAO-F | 3 | 80 |
| CCAR-F | 12 | 80 |
| CCDV-F | 0 | 79 |
| CCAR-P | 0 | 80 |

- **Tier 1:** the sample questions in Anthropic's official exam guides (v1.0), which you can get from
  the [official certification page](https://anthropic-partners.skilljar.com/page/partner-certifications).
- **Tier 2:** questions from Amey Thakur's open-source
  [CLAUDE-CERTIFICATIONS](https://github.com/Amey-Thakur/CLAUDE-CERTIFICATIONS) repo, shared under the
  MIT licence. The licence is in [`LICENSE-amey-thakur.txt`](LICENSE-amey-thakur.txt) and at the top of
  `index.html`. For each exam this includes the 45 questions of Amey's mocks 1 to 3 (44 for CCDV-F, after one was left out), so if you want
  those mocks fresh, take them on his repo before your first mock here.

A 60-question mock uses most of an exam's bank, so later mocks repeat many questions. Use repeats
for pacing and for **Fix my mistakes**, not as proof you're ready.

Before publishing, two subject experts checked a random sample of 40 answer keys (10 per exam)
against Anthropic's docs and exam guides. From that check, one wrong key was corrected, one
rationale was brought up to date, and one ambiguous question was left out. The list is in
`tools/build_practice.py` (`FIXES` and `EXCLUDE`). If you find another wrong answer, report it with
the site's **Report a problem** form.

Only questions whose authors allow sharing go in. Questions copied from paid or partner courses,
and questions whose author hasn't agreed, stay out. The quality gate (`tools/gate.py`) refuses the
build if any other source appears.

## How it's built

`tools/build_practice.py` builds `index.html` from `question-bank.json` and `src/template.html`.
`tools/publish.sh` runs it on every release. Don't edit `index.html` by hand.

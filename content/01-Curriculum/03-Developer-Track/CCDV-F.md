# Developer track · CCDV-F Claude Certified Developer: Foundations

**Exam:** 53 questions · $125 list · 8 domains · check the time and pass mark in the [official guide](https://anthropic-partners.skilljar.com/page/partner-certifications)
**Study time:** 10–15 hours on top of CCAR-F, about 2 weeks. **Book it within 2 weeks of passing CCAR-F.**
**What others learned:** [Insights](../../11-Lessons-Learned/INSIGHTS.md#ccdv-f-developer-foundations)

**Who it's for:** engineers building with the Claude API, Claude Code and MCP. About two-thirds of
it overlaps with CCAR-F, so this file focuses on what's new.

## Week plan

| Week | Focus | Do |
| --- | --- | --- |
| 1 | **Applications and Integration (33%)** and **Model Selection (17%)**, the parts CCAR-F doesn't cover | Lessons L00–L02, then SIM-02. API mechanics: messages, streaming, vision, extended thinking, prompt caching, batch vs real time, Bedrock and Vertex. Course: the rest of Building with the Claude API. Lab 04: run the same task in real time, with caching and through the Batch API, then compare cost and latency. Read the matching pages in [Anthropic's API docs](https://platform.claude.com/docs) (Tier 1). |
| 2 | Agents, tools and MCP, and security (review) | Lessons L03–L07, then SIM-03 to SIM-05. Review CCAR-F lessons L01 and L02 (agents, tools and MCP).

# CCDV-F simulations

These six scenarios are **our own**. The Developer exam guide publishes no official scenario list,
so each one is written from the guide's Section 6 objectives and the saved Claude docs. Rehearse all
six. Across SIM-02 to SIM-07 the 60 decisions roughly follow the exam weights, so Applications and
Integration (Domain 2) gets the most practice.

L01-applications-and-integration, L02-model-selection-and-optimization, L03-agents-and-workflows,
L04-prompt-and-context-engineering, L05-tools-and-mcps, L06-security-and-safety,

**Lesson** column (for example "[Lesson 1, section 2.3](../../02-Lessons/03-CCDV-F-Developer/L01-applications-and-integration.md)") points at Domain 2, skill 3, inside L01.

Each scenario has 10 decisions, and every answer in the key cites an official objective (for
example "D2 Claude API Mechanics") and the lesson section that teaches it.

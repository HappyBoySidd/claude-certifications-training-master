## How to use

1. Read the lesson, then do its "Try it" exercise.
2. Drill that domain in the practice tool without peeking; aim for 80% or more.
3. Note the result.


## Recommended order

**L00 first**, then the biggest domains: **L01 Integration (19%)**, **L02 Solution Design (17%)**,
**L03 Evaluation (16%)**, then L04 through L07. Governance and stakeholder communication together are
28% of the exam, so don't skim L04 and L05. After the lessons, do the
[simulations](../../04-Simulations/04-CCAR-P-Architect-Professional/README.md).

## Before you start

CCAR-F is **recommended but not required**. Several lessons here link back to it rather than
re-teaching. If you haven't done it, skim the
[CCAR-F lessons](../02-CCAR-F-Architect-Foundations/README.md) first.

Source: official exam guide v1.0 (sections 4–6); `11-Lessons-Learned/INSIGHTS.md` (CCAR-F not
